# ALFADEL interface screenshots

These screenshots document the ALFADEL v0.1.2 interface and its two editorial workflows.

1. `01-main-interface.png` — text loaded before analysis in Preserve historical forms mode.
2. `02-analysis-in-progress.png` — lexical and morphological analysis in progress.
3. `03-standardization-historical-normalization.png` — historical spelling identified in Standardize mode and canonical form proposed.
4. `04-standardization-correction-example.png` — a standardization/correction candidate with supporting evidence.
5. `05-preserve-historical-forms.png` — Preserve mode, including the distinct `standard → historical option` state.

The screenshots are documentation only. The restricted lexical resources and controlled corpus are not included in this repository.
